# 🌟 Auri Luvia Glowly - Lean MVP Roadmap

> **Mission:** Простое, минималистичное приложение для организации косметических продуктов с социальными функциями  
> **Team:** iOS Dev + Backend + AI Engineer + Designer  
> **Timeline:** 10-11 недель до MVP релиза  
> **Architecture:** 5 Tab Bar Items (Косметичка, Лента, Добавить, Обучение, Профиль)

---

## 📊 Анализ текущего состояния

### ✅ Что уже построено (40% готово)
- **UI Foundation:** Красивый SwiftUI интерфейс с системой тем
- **Authentication:** Face ID, Touch ID, Email/Password, Google OAuth
- **Product Management:** Базовые CRUD операции, категории, отслеживание срока годности
- **Onboarding:** Анкета профиля пользователя (тип кожи, цели, аллергии)
- **Notifications:** Напоминания о сроке годности, уведомления о рутине
- **Export/Share:** JSON export функциональность
- **Network Layer:** Базовая инфраструктура (нужна интеграция с backend)

### ❌ Критические пробелы для MVP
- **Backend Integration:** Все данные локальные, нет синхронизации
- **Sharing Feature:** Deep links не реализованы
- **Learning Content:** Нет системы статей или советов
- **AI Integration:** Chat интерфейс есть, но нет подключения к backend

## 🎯 MVP Core Features (v1.0)

### 1. **Product Organizer** (Primary Feature)
**User Value:** "Я могу легко отслеживать и организовывать свою косметику"

#### Основная функциональность:
- ✅ Добавление продуктов (вручную, фото, штрихкод)
- ✅ Фильтрация по категории, бренду
- ✅ Поиск продуктов
- ✅ Детали продукта (ингредиенты, использование, преимущества)
- ❌ **Убираем:** Отслеживание срока годности, уведомления о просрочке

#### Технические требования:
- Backend API для синхронизации продуктов
- Загрузка/хранение изображений
- Offline-first архитектура
- Миграция с UserDefaults на Core Data

### 2. **Cosmetic Bag Sharing** (Secondary Feature)
**User Value:** "Я могу поделиться своей коллекцией с друзьями"

#### Основная функциональность:
- Генерация deep links для косметичек
- View-only доступ к чужим коллекциям
- Простое sharing через Messages/WhatsApp
- **Новый flow:** Deep link → App Store → Скачивание → Просмотр чужой косметички → Регистрация

#### Технические требования:
- Backend sharing API
- Обработка deep links
- App Store redirect для не-пользователей
- Web preview для не-пользователей

### 3. **Learning Content** (Tertiary Feature)
**User Value:** "Я получаю полезные советы по красоте и напоминания"

#### Основная функциональность:
- Кураторские статьи о красоте (5-10 статей для MVP)
- Умные уведомления с юмором
- Базовые советы по красоте на основе профиля пользователя
- Сезонные напоминания

#### Технические требования:
- Content management system
- Push notification system
- Отслеживание предпочтений пользователя
- Простая CMS для обновления контента

## 🛠 Техническая архитектура

### Текущий стек
- **Frontend:** SwiftUI + Combine
- **Storage:** UserDefaults → Core Data (нужна миграция)
- **Network:** URLSession + custom NetworkService
- **Auth:** Keychain + JWT tokens
- **Images:** Local storage → Cloud storage (нужна миграция)

### MVP стек
- **Frontend:** SwiftUI + Combine (оставляем текущий)
- **Storage:** Core Data + CloudKit sync
- **Backend:** REST API + PostgreSQL
- **Images:** AWS S3 или аналогичный CDN
- **Notifications:** Firebase или Apple Push
- **Analytics:** Firebase Analytics

## 🎨 UX/UI Analysis & Improvements

### Current UX Issues Identified:

#### 1. **Product Organizer (BagListView)**
**Issues:**
- Слишком много информации о просрочке (badges, counters)
- Сложная категоризация (4 основных + подкатегории)
- Перегруженный header с expiry counters

**Improvements:**
- Убрать все expiry-related UI элементы
- Упростить категории до 2-3 основных
- Упростить header - только счетчик продуктов
- Сделать ProductCard более минималистичным

#### 2. **Add Product Flow (AddEntryChooserView)**
**Issues:**
- ActionSheet устарел (deprecated в iOS 17)
- Слишком много шагов для добавления
- Неясный flow для фото

**Improvements:**
- Заменить ActionSheet на современный UI
- Упростить до 2 опций: "Вручную" и "Фото"
- Улучшить UX для фото-добавления

#### 3. **Product Card (ProductCard)**
**Issues:**
- Перегружен expiry badges
- Слишком много информации
- Сложная цветовая схема

**Improvements:**
- Убрать все expiry-related элементы
- Оставить только: название, бренд, категория
- Упростить цветовую схему
- Сделать более минималистичным

### UX Improvement Plan:

#### Week 1: Core UI Simplification
- [ ] Убрать expiry tracking из всех UI компонентов
- [ ] Упростить ProductCard (убрать badges, упростить layout)
- [ ] Упростить BagListView header

#### Week 2: Flow Optimization
